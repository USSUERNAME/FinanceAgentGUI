# 종목 분석 8단계 표준

## 목적

`#stock`에 새 탭이나 별도 판정 체계를 만들지 않는다. 기존
`web/src/arca/stockCandidateVerification.js`를 단일 진입점으로 유지하고, 그 안의 근거 게이트와
통합 리서치 구조를 8단계로 확장한다.

화면에는 서로 다른 세 가지 상태를 섞지 않고 나란히 표시한다.

- **리서치 신뢰등급**: 근거가 믿을 만한지를 A/B/C로 판정한다.
- **분석 완성도**: 8단계 중 자료가 채워진 수를 `6/8`처럼 표시한다. 등급을 바꾸지 않는다.
- **매매 준비도**: 사용자가 고른 `tradeHorizon`에 필요한 축이 모두 준비됐는지 표시한다.

## 0단계 결정

### 필드 역할

| 역할 | 뜻 | 누락 시 처리 |
|---|---|---|
| `gate` | 리서치 신뢰등급을 결정하는 필수 근거 | 등급 하락 |
| `horizon_gate` | 특정 매매 유형의 실행 준비 조건 | 해당 유형의 매매계획 차단 |
| `display` | 분석 깊이를 보여주는 항목 | `자료 부족` 등 상태 표시 |
| `context` | 판단 배경 | 참고용이며 등급과 무관 |

새 게이트는 7단계 시뮬레이션을 통과하기 전까지 실제 등급 판정에 넣지 않는다. 현재 후보가 모두 C로
떨어지는지 먼저 계산한 뒤 활성화한다.

### 매매 유형

`tradeHorizon`은 사용자가 고르는 값이며 `day`, `earnings`, `position`, `long_term` 중 하나다.
선택하지 않은 값은 `unclassified`로 저장한다. 선택하지 않았다는 이유만으로 리서치 신뢰등급을
낮추지는 않지만, 매매계획과 비중 제안은 허용하지 않는다.

| 유형 | 필수 분석 축 |
|---|---|
| 데이 | 거래 적합성, 차트·매매계획 |
| 실적 | 거래 적합성, 시장 기대, 촉매·위험, 차트·매매계획 |
| 포지션 | 거래 적합성, 밸류에이션, 촉매·위험, 차트·매매계획 |
| 장기 | 사업 구조, 성장의 질, 재무 3표, 밸류에이션, 촉매·위험 |

### 누락 데이터

모든 새 필드는 아래 상태 중 하나를 가진다. 빈칸을 추정치로 채우지 않으며, 누락 상태는 게이트를
통과한 것으로 계산하지 않는다.

| 상태 | 화면 문구 | 의미 |
|---|---|---|
| `verified` | 검증됨 | 기준일과 출처가 확인됨 |
| `insufficient` | 자료 부족 | 필요한 자료가 현재 없음 |
| `accumulating` | 축적 중 | 수집 중이며 판정하기 이름 |
| `collection_failed` | 수집 실패 | 수집 작업이 실패함 |
| `stale` | 갱신 필요 | 마지막 정상 자료가 유효기간을 지남 |

`수집 실패`는 `이벤트 없음`이나 `자료 없음`으로 바꾸지 않는다. 화면에 마지막 정상 수집 시각과 실패
원인을 함께 표시한다.

## 종목 8단계

정확한 필드 경로·단위·출처 유형은 `config/stock-analysis-framework.json`을 기준으로 한다.

| 단계 | ID | 기존 연결 및 확장 | 기본 역할 |
|---:|---|---|---|
| 1 | `business_structure` | `integratedResearch.businessSummary`에 제품·지역·반복매출 비중 추가 | display |
| 2 | `trade_suitability` | 시총, 평균 일거래대금, 스프레드, ATR, 유통주식수 | gate + display |
| 3 | `growth_quality` | 물량·가격·믹스·M&A 성장 분해 | display |
| 4 | `financial_statements` | `financialRows`, `segmentRows`와 재무 경고 조합 | display |
| 5 | `market_expectations` | EPS·매출 컨센서스, 추정치 변화, 옵션 예상 변동폭 | earnings horizon_gate |
| 6 | `valuation` | `valuationScreen`과 섹터 KPI 사전 | position/long_term horizon_gate |
| 7 | `catalyst_risk` | 촉매, 반대근거, 무효화조건 | gate + display |
| 8 | `technical_trade_plan` | 진입·추가·정리 조건, 최대손실, 포지션 크기 | horizon_gate |

## 신뢰 게이트 목표안

시뮬레이션 대상 핵심 게이트는 다음 일곱 가지다.

1. 티커 식별
2. 공식·1차 출처
3. 검증 사실 2개 이상
4. 반대 근거
5. 투자 가설 무효화 조건
6. 데이터 기준일과 갱신 시각
7. 거래 적합성

이 항목은 “믿을 수 있는 후보인가”만 판단한다. 8단계 완성도와 매매 유형별 준비도는 별도다.
비중 제안은 신뢰 게이트와 선택한 매매 유형의 필수 축을 모두 통과한 경우에만 허용한다.

## 판정 문구 사전

| 내부 상태 | 화면 문구 |
|---|---|
| aligned | 방향 정렬 |
| mixed | 방향 엇갈림 |
| dispersed | 의견 분산 |
| insufficient | 자료 부족 |
| accumulating | 축적 중 |
| collection_failed | 수집 실패 |
| stale | 갱신 필요 |
| authoritative | 공식 근거 확인 |
| discovery | 탐색 신호 |
| invalidated | 무효화 조건 충족 |

출처 없는 숫자는 `미검증`으로 표시한다. 종합 사이트에서 발견한 값은 공식 자료로 재확인하기 전까지
게이트 근거로 세지 않는다.
