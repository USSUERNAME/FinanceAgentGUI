# Research Intelligence

주식채널+의 애널리스트 리서치 화면은 국내외 리포트를 같은 승인 흐름에서
다루되, 원문 권리와 발행사별 표현을 보존한다.

## Google Drive 폴더

연결된 리서치 루트 아래에서 최대 3단계의 하위 폴더를 탐색한다.

```text
Research/
  KR/
  GLOBAL/
    US/
    EU/
    JP/
```

`KR`, `US`, `EU`, `JP`, `GLOBAL` 폴더는 시장 구분으로 사용된다. 기존처럼
루트 폴더에 직접 올린 국내 PDF도 발행사 이름에 `증권`, `투자증권`,
`자산운용` 등이 있으면 국내 리서치로 호환 분류한다.

파일명에 시장 토큰을 넣는 방식도 지원한다.

```text
20260728_US_MorganStanley_Semiconductors_AI-Capex.pdf
20260728_JP_Nomura_Robotics_Outlook.pdf
20260728_SK증권_반도체_업황점검.pdf
```

## 공통 메타데이터

- `market_scope`: `KR`, `US`, `EU`, `JP`, `GLOBAL`, `UNKNOWN`
- `issuer_country`
- `original_language`
- `base_currency`
- `source_type`
- `original_rating`과 `normalized_rating`
- `target_price`와 `target_currency`

원문 투자의견과 목표가격은 발행 당시 표현과 통화를 유지한다. 발행사 간
컨센서스에는 별도의 공통 등급만 사용하며, 서로 다른 통화의 목표가격을
환산 기준 없이 직접 평균 내지 않는다.

## 리서치 인덱스

최근 16개 리서치 날짜를 읽어 수집량, 발행사 수, 구조화율, 국내외 비중,
명시적 의견의 방향성 균형을 계산한다. 방향성 균형은 명시적 의견이 있는
자료만 대상으로 하며 `긍정 +100`, `중립 0`, `경계·부정 -100` 범위로
표시한다. 명시적 의견이 없으면 점수를 만들지 않고 표본 부족으로 표시한다.

원문 투자의견이나 목표가가 구조화된 리포트는 별도의 신호 카드에 노출한다.
통화가 다른 목표가격은 환산 기준이 제공되기 전까지 합산하거나 평균 내지
않는다.

## 섹터 커버리지 지도

같은 날짜의 리포트를 섹터별로 묶어 리포트 수, 독립 발행사 수, 국내외
자료 비중, 구조화 완료 수, 명시적 의견 수를 함께 표시한다. 커버리지 깊이는
내용의 정답 여부가 아니라 독립된 출처가 같은 섹터를 얼마나 교차 확인했는지
나타낸다.

- `다원 확인`: 3개 이상 발행사와 4건 이상 리포트
- `교차 확인`: 2개 이상 발행사
- `단일 출처`: 한 발행사에만 의존

명시적 투자의견이 없는 리포트는 방향성 표본에 포함하지 않는다. 섹터명이
없는 거시·시장전략 자료는 보고서 유형에 따라 별도 종합 그룹으로 분류한다.

`데일리`, `전체리서치`와 같은 원문 표시는 산업 섹터가 아니라 문서 범위로
취급한다. 각각 `daily_digest`, `multi_sector_digest`로 분류하며 섹터
커버리지와 섹터 매핑 대기에서 제외한다. 거시·시장전략 자료도
`market_strategy` 문서 범위로 분리한다. 원문 표시는 리포트 카드에
보존하되 특정 산업의 독립 확인 표본으로 계산하지 않는다.

운송 자료는 `운송·물류` 표준 섹터에 연결한다. 항공사·항공화물·택배·육운·
해운사는 이 섹터에 포함하고, 항공기 제작·우주·방산은 `항공우주·방산`,
조선소·선박 기자재는 `조선·해양`에 유지한다.

## 섹터 표준화

`config/research-sector-taxonomy.json`이 국내외 리포트 집계용 공통 섹터
이름과 별칭을 관리한다. 예를 들어 `반도체`, `semiconductor`,
`Semiconductors`는 `반도체·AI 컴퓨트`로 함께 집계된다.

각 리포트의 `sectors`에는 원문 표현을 보존하고 `standardSectors`에 표준
섹터 ID와 표시명을 추가한다. 별칭 사전에 없는 이름은 버리지 않고 원문
그대로 독립 섹터로 남긴다. 커버리지 표에는 표준명과 함께 실제 원문
레이블도 표시한다.

별칭 사전에 없는 원문 섹터는 화면의 `섹터 매핑 대기`에 나타난다. 운영자는
표준 섹터를 선택한 뒤 `연결`을 눌러 별칭을 저장할 수 있다. 저장된 별칭은
설정 파일에 반영되며 화면을 다시 불러올 때 과거 리포트도 같은 표준 섹터로
재집계된다. 이미 다른 표준 섹터에 연결된 별칭은 중복 등록하지 않는다.

매핑 대기열은 기존 표준명과 별칭의 포함 관계를 이용해 최대 3개의 후보를
제안한다. `미디어업종`처럼 일반 접미사만 다른 명확한 경우에는 추천 후보를
기본 선택한다. `인터넷게임`처럼 여러 섹터가 동시에 가능한 복합 이름은
`검토 필요`로 표시하고 자동 저장하지 않는다. 모든 경우 최종 `연결`은
운영자가 직접 승인해야 한다.

커버리지 표의 섹터를 선택하면 해당 표준 섹터에 속한 리포트만 다시 모아
상세 패널을 만든다. 상세 패널에는 발행사 수, 주요 주장, 촉매, 위험,
확인 조건과 관련 리포트의 첫 근거가 표시된다. 이 내용은 기존 구조화
필드를 재배열한 것이며 새로운 사실이나 컨센서스를 임의로 생성하지 않는다.

최근 최대 16개 리서치 날짜에 같은 표준 섹터가 존재하면 상세 패널에 리포트
수와 독립 발행사 수 추이를 표시한다. 선택한 과거 날짜에서는 그 날짜 이후의
자료를 비교에 사용하지 않는다. 비교 가능한 날짜가 하나뿐이면 증감률이나
추세 판단을 만들지 않고 `축적 중`으로 표시한다.

같은 날짜별 섹터 집계에는 구조화된 주요 주장, 촉매, 위험과 확인 조건의
고유 문구도 보존한다. 화면의 `논점 변화`는 바로 이전 리서치 날짜와 최신
날짜의 문구를 정규화한 뒤 정확히 비교하여 `새로 수집`과
`이전 자료에서 소멸`로 나눈다. 의미가 비슷한 다른 문장을 같은 주장으로
간주하지 않으며, 소멸 표시는 해당 주장이 반박됐다는 뜻이 아니라 최신 수집
자료에 같은 문구가 없다는 뜻이다.

같은 날짜와 섹터에서 2개 이상의 독립 발행사가 정확히 같은 구조화 문구를
제시하면 `독립 발행사 반복 논점`으로 표시한다. 주장, 촉매, 위험을 구분하고
발행사 수와 리포트 수를 함께 노출한다. 이는 의미 기반 컨센서스 판정이
아니며, 반복 문구가 시장의 정답이나 투자 합의를 뜻하지 않는다.

`발행사 의견 분포`는 리포트 건수가 아니라 독립 발행사를 기준으로 긍정,
중립, 경계, 부정 의견을 집계한다. 같은 발행사가 여러 리포트를 냈더라도
같은 방향이면 한 표본으로 계산한다. 한 발행사 안에서 서로 다른 명시적
방향이 발견되면 `발행사 내부 혼재`로 분리하고 방향 정렬 계산에서 제외한다.
명시적 의견 발행사가 하나뿐이면 합의로 부르지 않으며, 두 곳 이상이고 한
방향이 67% 이상이면서 최소 두 발행사가 같은 방향일 때만 `방향 정렬`로
표시한다. 나머지는 `의견 분산`으로 표시한다.

## 권리 경계

운영자가 승인한 자료만 내부 구조화 분석 대상으로 사용한다. PDF 원문, 표,
이미지는 재배포하지 않으며 사용자 화면에는 요약, 구조화된 주장, 출처
참조만 표시한다. 공개 웹 리서치와 고객 전용 자료는 별도의 접근 상태로
기록해야 한다.
